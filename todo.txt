Colm vs cmux (manaflow-ai/cmux) — missing / stub features
=========================================================
CLI methods exist for many of these (dock.*, feed.*, vault.*, group.*,
custom-sidebar.*) but they are feature_store key-value stubs, not the
cmux product. "STUB" = API exists, UI/behavior does not.

P0 — daily agent workflow (what you keep hitting)
-------------------------------------------------
[x] Pane attention ring
    Unfocused panes with unread notifications get a blue #4C8DFF ring
    (.column-card.needs-attention). Focused pane stays .active only.
    workspaceFocused no longer bulk-marks every unread in the workspace.

    does not toast. Muted workspaces also drop banners.

    opencode, cursor, gemini, copilot, codebuddy, factory, qoder, kimi,

    bell.fill #4C8DFF "Needs input". Feed permission cards still P2.
